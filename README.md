# Fondest Memories
Fondest Memories adds unique dimensions inspired by Liminal Spaces. The Mod is currently in development, so expect things to change and bugs to be present.

### Shader Support
This mod does in fact work with Iris and Sodium. But support for other rendering mods is unlikely.

### Dependencies
This mod only depends on Fabric API

> Subject to change in the future
